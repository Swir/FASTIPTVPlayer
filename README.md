## 🚀 About

**FastIPTV Player** is a Python terminal application for organizing lawful M3U/M3U8 playlists, browsing channel groups, searching entries, managing EPG sources and launching selected streams in VLC Media Player.

The interface uses `Rich` for readable terminal output and includes configurable VLC and proxy settings.

It is designed for users searching for a **Python IPTV player**, **M3U playlist manager**, **M3U8 VLC launcher**, **EPG playlist tool** or a terminal-based channel browser for playlists they are authorized to use.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📂 Local playlists | Load M3U and M3U8 files |
| 🔎 Channel search | Find channels quickly |
| 🗂️ Groups | Browse playlist categories/groups |
| ▶️ VLC playback | Launch selected stream URLs in VLC |
| 📍 VLC path | Configure the VLC executable |
| 🌐 Proxy settings | Optional proxy configuration |
| 🗓️ EPG | Manage and process EPG sources |
| 🎨 Rich UI | Clean terminal menus and output |
| 📜 Error log | Records issues in `error.log` |

## 📦 Installation

```bash
git clone https://github.com/Swir/FASTIPTVPlayer.git
cd FASTIPTVPlayer
pip install -r requirements.txt
python run.py
```

VLC Media Player must be installed separately.
